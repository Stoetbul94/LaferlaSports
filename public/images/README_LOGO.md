# Logo File Location

Please place your Laferla Sports logo file in this directory with the filename:

**`logo.svg`** (preferred) or **`logo.png`** or **`logo.jpg`**

The logo should be:
- The metallic gold wolf head in shield design
- "LAFERLA SPORTING" text included
- Transparent or dark background (will work with dark theme)
- High resolution for crisp display

The logo will automatically appear in:
- Header navigation (top left)
- Footer (company info section)
- About page (centered at top)

If the logo file is not found, the site will fall back to text-only branding.
