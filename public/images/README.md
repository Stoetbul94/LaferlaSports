# Product Images

Place product images in the `products/` subdirectory.

## Image Naming Convention

Images should be named according to the product slugs defined in `lib/products.ts`:

- Format: `{product-slug}-{number}.jpg`
- Example: `capapie-competition-pistol-10m-air-1.jpg`

## Image Requirements

- Recommended format: JPG or WebP
- Recommended size: 1200x1200px minimum for product detail pages
- Aspect ratio: Square (1:1) for best display
- File size: Optimize images for web (under 500KB recommended)

## Placeholder Images

If product images are not available, the site will display a placeholder. You can replace the placeholder by adding actual product images following the naming convention above.
